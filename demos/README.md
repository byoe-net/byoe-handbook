# BYOE 示例代码

> 按主题分类的可运行示例，搭配 [docs/](../docs/) 食用效果最佳。

## 快速运行

```bash
pip install byoe
export OPENAI_API_KEY=sk-...
python demos/01-api/01_quickstart.py
```

## 目录

| 目录 | 内容 | 数量 | 前置知识 |

| [03-tools](03-tools/) | 自定义 Tool 子类 | 2 个 | 了解 Tool 基类 |
| [04-apps](04-apps/) | 完整应用模板（聊天机器人、提取器、流水线…） | 6 个 | Python 中高级 |

| [06-other](06-other/) | 其他场景（营销工作流、GitHub Actions） | 2 个 | 各场景领域知识 |
