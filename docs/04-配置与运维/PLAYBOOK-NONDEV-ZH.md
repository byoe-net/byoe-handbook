# BYOE 非研发场景落地手册（中小团队）

> 目标：把 skills、crew、swarm、loop 用在企业内部非软件流程。

---

## 1. 运营团队：活动执行闭环

### 推荐组合

- skills：活动复盘模板、投放诊断模板
- crew：运营负责人 + 内容 + 数据分析
- swarm：并行生成文案、渠道策略、预算建议
- loop：每 4 小时巡检投放异常

### 示例

```bash
byoe loop -p "检查投放数据异常并给出调整建议" --every 4h
```

交付物：日报、异常清单、调优建议。

---

## 2. 客服团队：工单质检与知识沉淀

### 推荐组合

- skills：标准回复规范、升级工单规则
- crew：客服主管 + 质检 + 知识库维护
- swarm：并行处理高优先级工单分类
- loop：每小时扫描未处理工单

### 示例

```bash
byoe loop -p "扫描未关闭工单，标记高风险并生成升级建议" --every 1h
```

交付物：高风险工单列表、升级建议、FAQ 增量。

---

## 3. 人事行政：招聘与入职流程

### 推荐组合

- skills：岗位筛选标准、面试反馈模板
- crew：招聘 + 用人经理 + 行政
- swarm：并行筛选简历与面试摘要
- loop：每日 18:00 汇总候选人状态

### 示例

```bash
byoe loop -p "汇总今日候选人进度并生成明日面试计划" --at 18:00 --max-runs 1
```

---

## 4. 财务与法务：合规巡检

### 推荐组合

- skills：合同审查检查项、报销稽核规则
- crew：财务 + 法务 + 审批负责人
- swarm：并行识别风险条款和异常报销
- loop：每日巡检并输出风险报告

---

## 5. 落地顺序（建议）

1. 先建 3 个高频 skills（模板化）
2. 再定 1 条 crew 标准流程（明确阶段和责任）
3. 再开 1 条 loop（固定时间自动执行）
4. 最后增加 swarm（并发提效）

原则：先稳定、再自动、再并行。

---

## 6. KPI 建议

- 平均处理时长（TAT）
- 重复问题占比
- 升级工单比例
- 人工审核通过率
- 每周自动完成任务数

这些指标可用于评估 BYOE 在非研发场景的真实 ROI。
