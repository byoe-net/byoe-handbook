# 卜一智航 (BYOE) 内置代码体检专家: Sober 扫描使用说明

> byoe.net | 适用版本: 0.8.0 及以上

在 AI 辅助编程（Vibe Coding）不断普及的今天，大模型生成代码的速度极快，但同时也特别容易遗留“技术债”——例如用不上的死代码、复制粘贴的冗余逻辑、几千行的“上帝类”、或是草率包含的安全隐患。 

为了对冲这种风险，我们在 **BYOE v0.7.x** 阶段完成了该能力的内置化，并在 **v0.8.0** 继续增强，通过纯 Python 原生重写提取了著名的静态防腐分析工具 [Sober Coding] 的核心引擎，并将其化作 BYOE 中的**全自动一级内置武器：`sober_scan` 工具**！

---

## 🧐 1. Sober_scan 能查出什么？

这套内置体检系统不依赖沉重的第三方语法树引擎，而是通过速度极快的跨语言正则与启发式模式匹配，极速为你找出以下典型 AI 坏味道：

* **🔒 安全隐患 (Security)**：硬编码的密码、Token、云服务 Key，或者直白的 SQL 注入拼接（`SEC-001`, `SEC-002`）。
* **🏛 架构腐坏 (Architecture)**：超过 500 行的超级“上帝文件”、混杂的 HTTP 和 DB 查询操作、超过 15 次的意大利面条式 Imports (`ARC-*`)。
* **💀 死代码 (Dead Code)**：被 `return` 或 `break` 之后彻底失效无用的盲肠代码段 (`DEAD-003`)。

---

## 🚀 2. 如何使用？(闭环全自动与手动扫描！)

因为 Sober 已经被我们定义为大模型的“第一顺位原生工具 (First-class tool)”，并深度整合至系统的命令行中，你现在有三种极其优雅的使用方式：

### 方式一：终端指令人工体检 (新！推荐)

你可以随时抛开大模型，将它当作一个纯粹的极客终端检查工具：
```bash
# 扫描当前项目的代码债并在控制台进行漂亮的彩色输出
byoe sober .

# 精确扫描特定目录，并将报告保存为 Markdown 格式
byoe sober src/utils/ --format md --out report.md
```
在控制台模式下，体检单会包括整体得分、缺陷严重程度分级、并提示具体的病灶坐标。

### 方式二：闭环全自动 (AI 自动修虫)

在 `byoe chat` 对话框中，当你刚让 AI 写完一大堆业务模块后，直接输入以下指令：

🗣 **你：** 
> *“代码写得差不多了。请调用 `byoe sober . --format md --out .sober_report.md` 生成报告。拿到报告后，请帮我阅读具体的错误项，并使用 `edit_file` 将里面评级为 CRITICAL 和 HIGH 的问题全部自动修复干净！”*

🤖 **AI 的应对路线：**
1. **执行指令**：它会自动调用 `bash` 进程帮你跑出干净无色的 Markdown 格式会诊单。
2. **拿取会诊单**：它调用 `read_file` 去读这个 md 体检表（包含分数、问题名称、具体到代码哪一行的准确定位）。
3. **精准打击**：大模型读懂了确切病灶坐标，像外科大夫一样，不再盲目搜代码库，而是直接使用 `edit_file` 对患处动刀，修剪干净！

### 方式三：AI 自发静默工具扫描

大模型的内置可用 Tool 里同样挂载了对等的 `sober_scan` API 工具。在你提出极其宽泛的要求（例如“重构整个 auth 目录所有的代码气味”）时，模型也会直接自主暗中调用 Python 原生扫描获得这批清单流。

## 🛠 3. 为什么一定要用它？

* **Zero-Friction（真正的零配置）**：因为 Sober 的核心功能已经被我们用 Python 重写融合进了 BYOE 底包中。您不需要去装 `NodeJS`，也不用跑 `npm install -g sober-coding`。**只要你的电脑有 `byoe`，你的系统就有 `sober`。**
* **最强配合**：纯用大模型去找大模型写的隐藏漏洞（所谓的大模型互审），极其浪费昂贵的 Token 且经常漏抓。利用轻量靠谱的静态扫描快速定位，再让大模型执行最后的手术修改，这是目前工业界验证的 **Token 消耗最少** + **准确度最高** 的闭环范式！ 

快去享受每次写完大型项目后，只需要一句话让 AI 自己清扫战场的畅快感吧！
