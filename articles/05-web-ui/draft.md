# Web 界面：可视化 AI 工作台

> 一句话摘要：`byoe web` —— 一个浏览器页面，管理对话、技能、任务、会话、Crew 和 Cosmos 可视化。

---

## 1. 场景引入

CLI 很酷，但不是所有人都喜欢黑底绿字的终端。你的产品经理、测试同事、甚至你自己，有时更想要一个**图形界面**。

---

## 2. 启动 Web

```bash
byoe web
```

```
BYOE Web UI → http://localhost:7860
```

> 插入 Web UI 全屏截图（`articles/05-web-ui/images/`）

---

## 3. 界面布局

Web UI 默认分为三个区域：

```
┌─────────────────────────────────────────────┐
│  状态栏 (StatusBar)                          │
├──────────────────────┬──────────────────────┤
│   对话面板           │    辅助面板           │
│   (ChatPanel)        │  ┌──────────────────┐│
│   ┌──────────────┐   │  │ 技能面板 (Skills)││
│   │ 消息历史      │   │  ├──────────────────┤│
│   │              │   │  │ 任务面板 (Tasks) ││
│   │              │   │  ├──────────────────┤│
│   │              │   │  │ 文件变更 (Diff)  ││
│   └──────────────┘   │  ├──────────────────┤│
│   ┌──────────────┐   │  │ 日志面板 (Logs)  ││
│   │ 输入框        │   │  ├──────────────────┤│
│   └──────────────┘   │  │ 会话面板         ││
├──────────────────────┴──────────────────────┤
│  状态栏底部 (模型、token 用量、连接状态)       │
└─────────────────────────────────────────────┘
```

### 对话面板

和 ChatGPT 类似，但有一个关键区别：AI 的回复中会清晰展示**工具调用过程**。

> 插入工具调用显示的截图

```
Assistant: 我来查看一下这个函数的逻辑。

🛠  read_file("src/utils.py")
📄 已读取 142 行代码

🛠  grep("def calculate_discount", "src/")
📄 找到函数定义

🛠  write_file("tests/test_utils.py")
📄 已写入 68 行测试代码

🛠  bash("pytest tests/test_utils.py -v")
📄 6 passed in 0.12s

✅ 已完成！测试覆盖了 6 个场景...
```

每个工具调用都可以展开/折叠，查看传入参数和返回结果。

### 辅助面板

通过底部的状态栏按钮打开：

| 面板 | 功能 |
|------|------|
| **Skills** | 查看/激活/导入技能 |
| **Tasks** | 定时任务管理（调度器） |
| **Diff** | 文件变更对比 |
| **Logs** | 实时执行日志 |
| **Session** | 会话列表/搜索/恢复 |
| **Crew** | Crew 工作区状态 |
| **Usage** | Token 用量统计 |

---

## 4. 技能面板的使用

> 插入技能面板截图

在 Skills 面板中你可以：
- **查看**已安装的技能列表（含触发词、使用次数、最后使用时间）
- **激活/停用**技能（对整个会话生效）
- **导入**新的 JSON 技能（粘贴或上传文件）
- **搜索**技能名称

---

## 5. 文件变更追踪（Diff 面板）

> 插入 Diff 面板截图

AI 修改文件时，Diff 面板会自动显示变更内容。绿色为新增，红色为删除。你可以：
- 逐文件查看 diff
- 一键接受或拒绝变更
- 展开完整文件内容

---

## 6. 多模型切换

Web UI 支持在设置中直接切换 LLM：

> 插入设置面板截图

```yaml
provider: openai
model: gpt-4o
temperature: 0
max_tokens: 16384
```

无需重启，切换后下一轮对话立即生效。

---

## 7. Cosmos 可视化模式

> 插入 Cosmos 截图

Cosmos 是 BYOE 的特色功能：将对话中的关键实体和关系**可视化**为节点图。适合：
- 理解复杂项目的架构关系
- 追踪任务依赖
- 展示 AI 的思考链路

---

## 8. 要点总结

- 启动 Web：`byoe web` → 浏览器访问 `http://localhost:7860`
- 面板化设计：对话 + 辅助面板（Skills / Tasks / Diff / Logs / Session / Crew / Usage）
- 工具调用可视化：每个 `🛠` 步骤可展开查看详情
- 文件变更追踪：Diff 面板直观对比修改前后
- Cosmos 可视化：对话实体关系图
