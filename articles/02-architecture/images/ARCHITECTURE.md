## 绘制要点

1. **四层分层明显**：用户界面 → Agent → LLM → Tools & Skills → 存储
2. **颜色区分**：每层一种颜色，Tools 层用多色块表示丰富的扩展性
3. **箭头简化**：用单向箭头表示调用链，双向箭头表示数据流
4. **大小比例**：LLM 层最小（BYOE 对 LLM 的封装很薄），Agent 层最复杂
